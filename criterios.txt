Baseball-TMS será una plataforma web para la gestión de torneos de béisbol bajo los 
siguientes criterios:

Frontend: El frontend será desarrollado utilizando HTML, CSS y JavaScript, para no depender de frameworks que puedan 
romperse con cada actualización o cambio en sus versiones. La interfaz se requiere que sea intuitiva, responsiva y 
fácil de usar para mejorar la experiencia del usuario, ya que parte de los usuarios finales pueden no estar 
familiarizados con tecnologías avanzadas (Interfaz con estilo deportivo). Se requieren los media queries más adecuados 
para que la interfaz se adapte a celulares, tabletas, laptops y pantallas de escritorio. Se utilizará JWT (JSON Web Tokens) para garantizar la seguridad y autenticación de los 
usuarios, siempre con el enfoque necesario para adaptarse a los roles de cada usuario. Los roles de usuario definidos en el backend 
(API/v1/) son:
- Administrador (control total sobre el sistema, incluyendo la gestión de usuarios (CRUD), perfiles, categorías (CRUD), equipos (CRUD)
campos (CRUD) y juegos (CRUD).)
- Manager/Entrenador (solo consulta informacion de los jugadores de su equipo, el calendario/historial de juegos en dashboard, tabla de posiciones, estadísticas de equipo y estadísticas de jugadores)
- Jugador (solo consulta su información personal, el calendario/historial de juegos en dashboard, estadísticas de equipo y estadísticas propias)

Detalles de diseño (Interfaz intuitiva, minimalista, con toque deportivo y acceso rápido a información relevante):
- El API que se consumirá se encuentra localizado en /API/v1/ (El que ya fue creado anteriormente).
- En la raíz del proyecto se creará la estructura de folders del frontend (scripts, styles, assets, etc.)
- El logo de plataforma es /assets/logo/sindicato.jpg
Utilizar los colores del logo proporcionado para darle el estilo a la interfaz de usuario.

NOTA: Todo será desarrollado SIEMPRE EN INGLÉS utilizando estándares en nomenclatura y comentando el código en la 
medida de lo posible.
